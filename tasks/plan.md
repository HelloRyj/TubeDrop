# 实现计划

1. 链接与画质：先写测试，验证规范化、拒绝危险输入、严格分辨率限制。
2. 下载工作进程：独立进程识别和下载，结构化进度与最终文件校验；网络测试。
3. Qt 界面：中文独立窗口，粘贴自动识别、选目录和画质、取消与错误恢复；离屏与可见窗口测试。
4. 打包：捆绑 Python、Qt、yt-dlp、FFmpeg 和 Node；验证 .app 启动，附完整源码和说明。

5. TikTok 扩展：复用 yt-dlp 下载流程；规范化完整视频链接，逐跳解析分享短链接；补充请求兼容组件、封面域名与回归测试后重建两端安装器。

6. 抖音与格式选择：先验证单视频与分享跳转，再添加 MP3 转换和格式界面；使用三平台 × 两格式的真实本地下载与音轨验证，最后重建 1.3 安装器并复核载荷。
